# PublinkSDK for Swift Package Manager

The Publink publisher SDK for iOS, as a binary xcframework hosted at
https://maven.publink.io, wrapped so Swift Package Manager can resolve it
together with its one dependency (Google IMA).

```swift
.package(url: "https://github.com/Adf-adserver/publink-sdk-spm", from: "1.6.0")
```

Each tag is one release. `Package.swift` is generated by the release workflow
in the Publink ad server repository; it holds only a URL and a checksum.
